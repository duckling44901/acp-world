# ACP World

Blender의 포털 공간과 ACP 공간을 브라우저에서 탐험하는 작은 WebGL 앱입니다. 열쇠 구멍을 통과하면 ACP World로 전환되고, WASD와 마우스 시선으로 3D 오브젝트 사이를 자유롭게 유영합니다. 직접 만든 아바타는 GLB 파일로 불러올 수 있습니다.

## 실행

Node.js가 설치된 상태에서 이 폴더에서 다음 명령을 실행한 뒤 `http://localhost:4173`을 엽니다.

```powershell
node .\serve.mjs
```

Three.js 모듈과 글꼴은 CDN에서 불러오므로 첫 실행에는 인터넷 연결이 필요합니다.

## 조작

- `W`, `A`, `S`, `D`: 바라보는 방향 기준으로 이동
- 마우스: 방향 조절
- `Space`, `C`: 상승과 하강
- `Shift`: 빠른 유영
- `Esc`: 포인터 잠금 해제, 화면을 클릭하면 다시 조작
- ACP World의 `열쇠 공간으로`: 포털로 돌아가기

## 아바타

상단 시작 카드의 **아바타 불러오기**에서 `.glb` 파일을 선택합니다. 불러온 모델은 임시 아바타를 대신해 공간을 이동합니다. 웹용 모델은 정면이 `+Z`인 GLB 기준이며, 모델 높이는 약 1.6m로 자동 맞춤됩니다.

## Blender 에셋

`assets/portal-space.glb`와 `assets/acp-world.glb`는 `../ACP_opening.blend`의 각 장면에서 내보낸 웹용 모델입니다.

오즈 스타일의 확장 씬은 프로젝트 폴더의 `ACP_opening_OZ.blend`에서 열 수 있습니다. ACP 중심을 고정한 채 공간 오브젝트를 20배 확장했고, 파스텔 광택 팔레트, 대형 궤도 링과 중심 부유 플랫폼을 추가했습니다.


상단의 **아바타 제작실**에서는 이름, 동물/로봇 형태, 색상, 장식과 머리 비율을 조정할 수 있습니다. 저장 시 아바타별 OZ-XXXX-XXXX 키가 발급되며 GLB 파일을 내려받아 ACP 공간에서 불러올 수 있습니다. 저장 키와 설정은 현재 브라우저에만 보관되므로, 같은 브라우저에서만 키로 다시 불러올 수 있습니다.
